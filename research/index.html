Questions I’m exploring

Research interests

My interests connect autonomous agents with the security and operational requirements of enterprise systems.

AI Agents

How can specialized agents coordinate dependent tasks across enterprise applications?

Agent Authorization

How can an agent preserve a user’s identity, access permissions, and delegated authority throughout a workflow?

Agent-to-Tool Security

How should tool access, API calls, and execution permissions be scoped and checked before an agent acts?

Enterprise AI Security

How can identity, data protection, and trust boundaries remain clear across models, integrations, and enterprise applications?

AI Observability

What evidence helps explain an agent’s decisions, tool calls, and outcomes during operation and investigation?

Secure-by-Design AI

How can security assumptions, approval points, and failure handling be considered early in an agent’s design?
