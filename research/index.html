Research interests

Autonomous AI Agents in Enterprise SaaS

Coordinating useful work across applications while keeping identity, access, and execution understandable.

I’m interested in how domain-specific agents coordinate tasks across enterprise applications, and how permitted actions, data access, and user context remain explicit as work moves between systems.

This theme connects agent orchestration with authorization-aware tool use, traceable execution, and human oversight.
